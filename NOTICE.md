## Licença

O README do projeto original declara a licença MIT, mas o repositório original não
inclui um arquivo `LICENSE`. Este fork adiciona o arquivo `LICENSE` com o texto da
licença MIT, mantendo o aviso de copyright do autor original ao lado do da EXPERTSA.

Todo o código herdado continua sendo obra de seus autores originais. As alterações
feitas neste fork estão listadas no [CHANGELOG](CHANGELOG.md).

nem endossado pelo Mautic ou pelos autores do projeto original.
